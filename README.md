# Three.js Portfolio

A modern 3D portfolio project built with **Three.js**, **Vite**, and **JavaScript**.

This repository documents my journey of learning and experimenting with Three.js by building interactive 3D experiences for the web. The current version focuses on creating an animated 3D sphere while exploring scene creation, camera setup, lighting, animation, and responsive rendering.

> 🚧 This project is currently under development and will continue to evolve with more interactive features.

---

## ✨ Features

- Interactive 3D Scene
- Animated Sphere
- Responsive Canvas
- Camera Controls
- Lighting Setup
- Smooth Animations
- Built with Vite
- Clean Project Structure

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/<your-username>/threejs-portfolio.git
```

Navigate into the project

```bash
cd threejs-portfolio
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
